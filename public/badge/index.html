Wir sind dabei!

Zeigen Sie auf Ihrer Website, dass Ihr Geschäft bei „Haan hat Herz“ mitmacht. Das Badge verlinkt direkt auf haanhatherz.de.

1. Größe wählen

2. Code kopieren

Variante A lädt das Badge direkt von haanhatherz.de und bleibt dadurch immer aktuell.

3. In die Website einfügen

  1. Öffnen Sie Ihre Website im Bearbeitungsmodus (bei Baukästen wie Wix, Jimdo, Squarespace oder WordPress meist ein „HTML“- oder „Code“-Element).
  2. Fügen Sie den kopierten Code an der gewünschten Stelle ein, zum Beispiel in der Fußzeile oder auf der Startseite.
  3. Speichern und veröffentlichen Sie die Seite. Fertig.

Variante B: Badge selbst hosten

Wenn Sie das Bild lieber auf Ihrem eigenen Server ablegen möchten, laden Sie es herunter, laden Sie es zu Ihrer Website hoch und tragen Sie bei src dessen Adresse ein.
